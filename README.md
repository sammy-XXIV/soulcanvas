# Soulcanvas

Tell it a precious memory. It turns it into art, then mints it as a soulbound NFT to your wallet on X Layer — so you can't lose it.

## Flow (draft)

1. Buyer tells the memory (freeform).
2. Agent offers to accept a reference photo; if none, asks up to 4 targeted follow-up questions (setting, the emotional beat, who else was there, one specific detail).
3. Generates a preview in the house art style.
4. Buyer confirms — only then does it mint (irreversible, so preview-then-confirm, never auto-mint).

## Status

Early scaffolding. Art style and question flow are still being drafted.
